# Keyboard Shortcuts

This page is generated from the terminal UI's key bindings (`app/ui/`). Do not edit it manually.

Press `?` or `F1` in the app to see these shortcuts.

## Main Window

| Keys | Action |
|---|---|
| `Space` | Toggle Checkbox |
| `x` | Exclude Checked |
| `i` | Include Checked |
| `r` | Reassign Checked |
| `v` | Range Select |
| `a` | Select/Deselect All |
| `Ctrl+L` | Lock/Unlock |
| `Ctrl+R` | Rename Node |
| `Ctrl+N` | New Folder |
| `+` | Rating (+) |
| `-` | Rating (-) |
| `Ctrl+O` | Settings |
| `Ctrl+K` | Model Manager |
| `Ctrl+W` | Wizard |
| `Ctrl+C` | CRO Ingest |
| `Ctrl+D` | DropZone |
| `Ctrl+S` | Scan |
| `Ctrl+Y` | History View |
| `Ctrl+U` | Quarantine Vault |
| `Ctrl+E` | Execute Plan |
| `Ctrl+A` | Audit Report |
| `Ctrl+X` | Extraction Preview |
| `Ctrl+B` | Browse Dir |
| `Ctrl+F` | Search Tree |
| `g` / `Shift+G` | Sample Dataset |
| `?` | Help |
| `F1` | Help (F1) |
| `Ctrl+Q` | Quit |

## Dialogs

`Esc` closes or cancels any dialog.

### Audit Report

| Keys | Action |
|---|---|
| `Ctrl+R` | Retry Selected Failed Item |
| `Ctrl+T` | Retry All Failed Items |
| `Ctrl+J` | Export JSON Report |
| `Ctrl+C` | Export CSV Report |

### Quarantine Vault

| Keys | Action |
|---|---|
| `r` | Release file |
| `d` | Dismiss item |
| `i` | Re-inspect item |
| `Ctrl+R` | Refresh vault |
